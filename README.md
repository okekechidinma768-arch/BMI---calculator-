# BMI Calculator — Frontend Mentor recreation

A responsive recreation of the Body Mass Index Calculator challenge using plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout, colors, responsive design
- `script.js` — metric/imperial input switching and BMI calculations

## Run it
Open `index.html` in a browser, or create a new HTML/CSS/JS Repl on Replit and copy each file into the matching file.

## Notes
This is a learning project inspired by the public challenge description. It is not a medical diagnosis tool. The illustration is CSS-drawn, so no image assets are required.
